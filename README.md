# 豆瓣显示评价人数

在豆瓣[选电影](https://movie.douban.com/explore)页面的评分旁边显示评价人数。

## 安装

需要先安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展，然后点击下方链接安装脚本：

[在 Greasy Fork 上安装](https://greasyfork.org/zh-CN/scripts/579773-%E8%B1%86%E7%93%A3%E6%98%BE%E7%A4%BA%E8%AF%84%E4%BB%B7%E4%BA%BA%E6%95%B0)

## 使用

打开 https://movie.douban.com/explore ，评分旁边会自动显示评价人数。
